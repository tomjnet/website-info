# Website info

Posts and research for my personal site. The website reads this repo directly, so a new post or paper goes live without rebuilding the site.

```
posts/       one Markdown file per post (+ posts/images/)
research/    one Markdown file per paper (+ PDFs)
index.json   generated by the GitHub Action — don't edit by hand
```

## Set up (once)

1. Create a **public** GitHub repo named `website-info` and copy this folder's contents into it, including the hidden `.github` folder.
2. Settings → Actions → General → Workflow permissions: choose **Read and write permissions** so the Action can commit `index.json`.
3. If the repo owner/name differ from `tomjnet/website-info`, update `contentRepo` in the website's `src/data/site.ts`.

## Write a post

Add `posts/YYYY-MM-DD-my-title.md` (the file name becomes the URL slug):

```md
---
title: "My title"
date: 2026-10-01
tags: [life, notes]
summary: "One line shown on the post card."
cover: posts/images/my-cover.png
draft: false
---

The post, in Markdown.
```

Images: put them in `posts/images/` and use relative paths, e.g. `![Diagram](./images/diagram.png)`.
Links to other posts: `[text](./other-post.md)`.

## Add research

Add `research/my-paper.md`, plus the PDF next to it if you have one:

```md
---
title: "Paper title"
summary: "Two or three sentences from the abstract."
status: published
venue: ResearchGate
date: 2026-09-01
url: https://www.researchgate.net/publication/...
pdf: my-paper.pdf
code: https://github.com/you/repo
tags: [physics, numerical-methods]
---
```

- `status`: `published`, `ongoing` or `idea`.
- `url`: where the paper lives. Clicking the row on the website opens it in a new window.
- `pdf`: file name of a PDF in `research/`; shown as a **PDF** link (opens in GitHub's viewer).
- `code`: shown as a **Code** link.
- `date`, `venue`, `pdf`, `code` are optional. Keep each field on one line.

## Publish

Commit and push. The **Build content index** Action updates `index.json`, and the change appears on the site within a few minutes (GitHub's raw file cache lasts about 5 minutes).

Set `draft: true` to keep a post or paper out of the index. You can rebuild the index locally with `node scripts/build-index.mjs`.
